# 🛒 PALACHARAK — Group Grocery List & Bill Splitting (€)

A clean, collaborative grocery shopping and group bill splitting web app in Euros (€).

---

## ✨ Features

- **🛒 Clean Grocery Checklist:** Simple, fast item adding with category chips and satisfying checkmarks.
- **🕒 Date & Time Tracking:** Exact timestamps for added items and supermarket checkout.
- **💶 Euro (€) Expense Splitting:** Clear debt simplification (*"Sam owes Alex €20.00"*) with 1-tap settlement.
- **👥 Member Directory & Working Admin Removal:** Admin can view online presence, login times, and remove members safely.
- **🔔 Mobile Push Alerts:** Alerts directly in the phone notification bar when friends add or buy items.
- **📱 Installable Phone App:** Add directly to home screen on Android and iPhone with full standalone mode.
